# 婴幼儿窒息风险与食物安全指南

> 参考来源：AAP 婴儿窒息预防指南、NHS 辅食安全建议、中国儿童膳食指南

## 高风险窒息食物（1 岁前需避免或改良）

| 食物 | 风险 | 安全替代 |
|------|------|----------|
| 整颗坚果 | 容易卡住气管 | 坚果酱、坚果粉稀释后少量尝试 |
| 爆米花 | 轻、小、易吸入 | 避免 |
| 硬糖、软糖 | 黏性强、易整块吞咽 | 避免 |
| 葡萄（整颗） | 大小形状易阻塞气道 | 纵向切成 1/4 或 1/8 |
| 樱桃番茄（整颗） | 大小形状易阻塞气道 | 纵向切开或压碎 |
| 整颗蓝莓 | 小而圆，易误吸 | 压破或纵向切开 |
| 热狗/香肠段 | 圆柱形易完全阻塞气道 | 纵向切条再切小段 |
| 生胡萝卜块 | 硬且圆 | 蒸软切小丁 |
| 生苹果块 | 硬且脆 | 蒸熟或切薄片 |
| 棉花糖 | 黏稠易粘住气道 | 避免 |
| 果冻 | 柔软但极易吸附气道 | 避免 |
| 口香糖 | 不可消化且易误吸 | 避免 |
| 鱼刺 | 尖锐危险 | 选择无刺鱼或彻底去刺 |

## 安全喂食姿势

- 让宝宝**坐直**进食
- 不要在宝宝哭闹、大笑时喂食
- 不要强迫喂食
- 喂食时家长应在旁看护
- 避免边吃边跑或躺卧

## 食物大小建议

### 6-9 个月
- 泥糊状为主
- 手指食物：蒸软的胡萝卜条、南瓜条，长约 5-6cm

### 9-12 个月
- 碎末、软颗粒
- 手指食物：蒸软的西兰花小朵、香蕉块

### 12-24 个月
- 软块、家常软食
-  still avoid: 整颗坚果、葡萄整颗、硬糖、爆米花

## 紧急情况处理

### 轻度呛咳
- 保持宝宝坐姿
- 鼓励宝宝继续咳嗽
- 不要拍背或掏嘴

### 严重窒息（无法咳嗽、无法发声、脸色发青）
- 立即拨打急救电话
- 同时实施婴幼儿海姆立克急救法
- 1 岁以下婴儿：拍背压胸法

## 海姆立克急救法（1 岁以下婴儿）

1. 将婴儿面朝下放在前臂上，头低臀高
2. 用手掌根部在婴儿背部两肩胛骨之间拍击 5 次
3. 将婴儿翻正，仰卧于前臂上，头低臀高
4. 用两指在婴儿胸骨下半段快速按压 5 次
5. 重复拍背和按压，直到异物排出或救援人员到达

## 预防建议

1. **学习婴儿/儿童急救法**
2. **进食时全程看护**
3. **避免边跑边吃**
4. **不要边看电视/手机边喂食**
5. **确保食物质地适合月龄**
