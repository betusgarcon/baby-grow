# 宝宝便秘饮食调理

## 什么是便秘
- 大便干硬、排便困难、排便间隔明显延长
- 添加辅食后容易因膳食纤维或水分不足出现

## 缓解便秘的食材
- **高纤维蔬菜**：菠菜、西兰花、南瓜、红薯、豌豆
- **水果**：梨、苹果、香蕉、火龙果、西梅
- **粗粮**：燕麦、小米、红薯
- **充足水分**：两餐之间适量喂水

## 便秘期间推荐食谱
- 梨泥、苹果泥、燕麦香蕉泥
- 菠菜泥、南瓜红薯泥
- 火龙果米粉糊

## 需要避免的做法
- 不要只喂米粉和白粥
- 不要过早添加高蛋白、低纤维饮食
- 不要依赖果汁通便（纤维素被破坏）

## 何时就医
- 超过3天未排便且伴随腹胀、哭闹
- 大便带血
- 体重增长异常
