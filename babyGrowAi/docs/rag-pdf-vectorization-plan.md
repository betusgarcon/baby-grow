# 《中国居民膳食指南（2022）》文本向量化方案

> 目标：把扫描版 PDF 图书转成可用于 RAG 的结构化文本，并完成分块、向量化与入库。
> 适用对象：`docs/rag_docs/` 下的全部参考资料（本方案以膳食指南为主线，其余书籍同理）。

---

## 一、文档实测结论（先看清对手）

对 `docs/rag_docs/中国居民膳食指南（2022）.pdf` 做了实测，关键事实如下：

| 项目 | 实测结果 |
|------|----------|
| 页数 | 378 页 |
| 文件大小 | 359,223,871 字节（约 343 MB） |
| 页面尺寸 | 538.56 × 737.76 pts |
| 生成方式 | PDFPatcher 0.6.2 + iTextSharp 5.5.14 |
| **字体表** | **空（无任何嵌入字体）** |
| **文本层** | **无**：`pdftotext -f 20 -l 20` 输出为空 |
| 每页构成 | 1 张整页 JPEG 图，2100×3100 px，RGB，300 DPI，约 800 KB/页 |

**结论：这是一本纯图片扫描书，没有任何可提取的文本。因此第一步必须是 OCR，而不是"解析 PDF 取文本"。**

这一点决定了整个方案的形态：**PDF 解析不是重点，OCR + 版面还原才是重点，也是唯一的高风险环节。**

### 1.1 版式元素清单（抽样页：1、7、8、9、10、20、40）

| 元素 | 出现位置示例 | 对 RAG 的价值 | 处理难点 |
|------|--------------|---------------|----------|
| 封面（纯图） | 第 1 页 | 低，可跳过 | 无文本，OCR 会产出噪声 |
| 序 / 前言 | 第 7–9 页 | 中，背景说明 | 无 |
| **平衡膳食准则八条** | 第 10 页起 | **极高**，核心结论 | 中英双语标签「准则一 / Enjoy a varied…」需配对 |
| 分级标题 | `【实践应用】`、`（一）什么是食物多样…`、`1. 平衡膳食模式` | 极高，决定分块边界 | 需识别层级（部分 > 章 > 节 > 子节） |
| 正文段落 | 全书 | 高 | 无 |
| **贴士框** | 第 20 页右下「贴士：6 月龄内婴儿纯母乳喂养…」 | 高，实操建议 | 圆角框，需与正文区分 |
| **简单表格** | 第 20 页「表 1-2 建议摄入的主要食物种类数」3 列 | **极高**，数值事实 | 需保留为结构化表格 |
| **宽表（重点）** | 第 40 页「表 1-13 常见食物的血糖生成指数」**6 列 = 3 组并排** | **极高**，GI 数据 | **线性 OCR 必错行**，必须结构化识别 |
| 资料来源注 | 表格下方「资料来源：《中国食物成分表标准版…》」 | 中，可溯源 | 需与所属表格绑定 |
| 侧栏竖排文字 | 第 20/40 页右侧「第一部分 一般人群膳食指南」 | 中，可作章节元数据 | 竖排，OCR 易乱；建议按坐标丢弃并另取 |
| 页码 | 页脚 | 低 | 清洗时剔除 |
| 插图 / 食物照片 | 全书散见 | 低（正文图） | 可保留占位 + 可选生成图注 |

### 1.2 书籍结构（用于构建元数据）

2022 版的组织结构大致为：

```
序 / 前言
平衡膳食准则八条            ← 核心结论，检索命中率最高的区域
第一部分  一般人群膳食指南
第二部分  特定人群膳食指南   ← 孕妇乳母 / 0-6月龄 / 7-24月龄 / 学龄前 / 学龄 / 老年 / 素食
第三部分  平衡膳食模式和膳食指南编写说明
附录（DRIs 膳食营养素参考摄入量、食物成分、食谱等）
```

这个层级必须在 Markdown 里还原成标题层级，后续才能做"按章节过滤"和"面包屑上下文"。

## 二、总体流程

```
PDF（纯图片）
   │
   ├─① 页面拆图（pdfimages，无损抽取整页 JPEG）
   │
   ├─② OCR + 版面分析（PP-Structure / MinerU / 云 OCR）
   │        └─ 输出：带结构的 Markdown（标题、段落、表格、图注）
   │
   ├─③ 人工/规则清洗 + 结构化规范（统一标题层级、表格规范、去页眉页脚）
   │        └─ 输出：data/guides/中国居民膳食指南2022/*.md
   │
   ├─④ 结构感知分块（按章节切，表格不切断，加面包屑）
   │
   ├─⑤ 向量化（bge-m3，1024 维）+ BM25 tsvector
   │
   └─⑥ 入库（KnowledgeDocument / KnowledgeChunk，幂等 upsert）
```

## 三、阶段一：OCR 与版面还原（决定成败）

### 3.1 工具选型

| 方案 | 中文 OCR | 表格还原 | 版面分析 | 成本 | 适用性 |
|------|---------|---------|---------|------|--------|
| **MinerU / magic-pdf**（opendatalab） | 强 | 强（输出 HTML/Markdown 表） | 强 | 免费，本地 | **首推**，专为中文扫描书/论文设计 |
| **PaddleOCR PP-StructureV3** | 很强 | 强 | 强 | 免费，本地 | 次推，表格识别优秀，生态成熟 |
| 云 OCR（合合 TextIn / 百度 / 腾讯） | 很强 | 很强 | 强 | 按页收费 | 预算允许时最省心，表格最准 |
| Tesseract + chi_sim | 中 | **弱** | 弱 | 免费 | **不推荐**，宽表必错行 |

**推荐路线：先用 MinerU 或 PaddleOCR 本地跑试点；若表格质量不达标，再对"表格页"单独走云 OCR。**

### 3.2 表格处理（本方案最关键的细节）

以「表 1-13 常见食物的血糖生成指数」为例，它是 **6 列 = 3 组「食物名称 | GI」并排** 的宽表：

```
食物名称 | GI | 食物名称 | GI | 食物名称 | GI
大米饭   | 83 | 甘薯(红,煮)| 77 | 菠萝   | 66
...
```

- 线性 OCR（逐行读字）会把三组数据串成一行，**数据完全错乱**。
- 必须使用**结构化表格识别**（PP-Structure / MinerU / 云表格识别），还原成 HTML `<table>` 或 Markdown 表格后，再决定是否"拆列重组"。
- 建议：宽表**保留原样为 HTML 表格**（Markdown 管道表对 6 列以上渲染差、LLM 也易读错），并在 chunk 里额外附一段自然语言摘要。

### 3.3 其他版面处理规则

| 元素 | 处理方式 |
|------|----------|
| 页眉 / 页脚 / 页码 | 按页面坐标区域裁掉 |
| 侧栏竖排文字 | 按坐标裁掉；其内容（如"第一部分 一般人群膳食指南"）改由**章节结构元数据**提供 |
| 封面、纯图页 | 跳过，不产出 chunk |
| 正文插图 | 保留 `![图注](figures/xxx.png)` 占位；可选：用视觉模型（qwen2.5-vl / GPT-4o）为图生成一句图注 |
| 贴士框 | 统一转成 Markdown 引用块 `> 贴士：…` |
| 中英双语标签 | `准则一 食物多样，合理搭配` + `Enjoy a varied and well-balanced diet` 合并为一个条目 |

### 3.4 输出目录（中间产物）

```
docs/rag_docs/_work/
├── images/               # ① pdfimages 抽取的整页 JPEG（378 张）
├── ocr_markdown/         # ② OCR 原始 Markdown（每页/每章一个文件）
├── cleaned_markdown/     # ③ 清洗后的成品 Markdown（待入库）
└── qc/                   # 质量抽查记录、覆盖率统计
```

## 四、阶段二：结构化 Markdown 规范（目标产物）

产物要和现有 `data/guides/*.md` 的规范一致（现有入库逻辑按 `\n##\s+` 切分 guide）。

### 4.1 标题层级映射

| 书中层级 | Markdown | 示例 |
|----------|----------|------|
| 部分 | `#` | `# 第二部分 特定人群膳食指南` |
| 章/人群 | `##` | `## 孕妇、乳母膳食指南` |
| 节 | `###` | `### 孕期妇女膳食指南` |
| 子节 | `####` | `#### 1. 补充叶酸，常吃含铁丰富的食物` |

> 建议：**一个 `##` 章 = 一个落盘文件**（如 `02-pregnant-lactating.md`），便于增量维护与幂等重跑。

### 4.2 元素规范

```markdown
# 第二部分 特定人群膳食指南

> 来源：《中国居民膳食指南（2022）》· 中国营养学会 · 人民卫生出版社
> 页码：PDF p.120–p.180

## 孕妇、乳母膳食指南

### 孕期妇女膳食指南

#### 1. 补充叶酸，常吃含铁丰富的食物

孕早期…（正文段落）

> **贴士**：6 月龄内婴儿纯母乳喂养，2 岁以上健康人群采用平衡膳食模式。

表 1-13 常见食物的血糖生成指数

| 食物名称 | GI | 食物名称 | GI | 食物名称 | GI |
|---------|----|---------|----|---------|----|
| 大米饭 | 83 | 甘薯（红，煮） | 77 | 菠萝 | 66 |

资料来源：《中国食物成分表标准版（第 6 版第一册）》，2018 年。
```

### 4.3 每个文件的 Front-matter（元数据）

```yaml
---
source: 中国居民膳食指南（2022）
publisher: 人民卫生出版社
author: 中国营养学会
edition: 2022
part: 第二部分 特定人群膳食指南

```

`population` 字段直接对接 `PopulationRouter`（现有 `app/services/rules/` 的人群路由），是后续"按人群检索"的关键。

## 五、阶段三：分块（Chunking）策略

原则：**结构优先，宁可少切，不可切碎语义单元。**

| 规则 | 说明 |
|------|------|
| 主切分点 | `##` / `###` 标题边界 |
| 长度控制 | 单 chunk 目标 512–1024 token；超长按段落二次切分，overlap 10–15% |
| 表格 | **绝不切断**；表格 + 所属标题 + 资料来源注 = 一个 chunk |
| 贴士框 | 与所在小节合并为一个 chunk（属于同一语义单元） |
| 面包屑头 | 每个 chunk 正文前注入上下文，如 `【第二部分 特定人群膳食指南 > 孕期妇女膳食指南 > 补充叶酸】`，显著提升检索命中 |
| 表格双写（可选） | 除原表外，用 LLM 生成一段「本表说明：大米饭 GI=83，属高 GI 食物…」的自然语言 chunk，提升语义检索召回 |

### 5.1 chunk_metadata 设计（对接现有 `KnowledgeChunk.chunk_metadata`）

```json
{
  "source": "中国居民膳食指南（2022）",
  "doc_type": "guideline",
  "part": "第二部分 特定人群膳食指南",
  "chapter": "孕妇、乳母膳食指南",
  "section": "孕期妇女膳食指南",
  "title_path": ["第二部分", "孕妇、乳母膳食指南", "孕期妇女膳食指南", "1. 补充叶酸"],
  "block_type": "text | table | tip",
  "table_id": "1-13",
  "population": ["pregnant"],
  "pdf_page_start": 140,
  "pdf_page_end": 141
}
```

`block_type` 让检索可以按需过滤；`table_id` 支持精确定位；`pdf_page_*` 支持回溯原文。

| 环节 | 现有实现 | 本方案用法 |

| 分块表 | `KnowledgeChunk(document_id,chunk_no,content,chunk_metadata,embedding,search_vector)` | 写入上面的 metadata |

### 6.1 入库代码改动

在 `app/knowledge/ingest.py` 旁新增一个加载器（**不改动现有 recipe/guide 逻辑**）：

```
app/knowledge/
├── ingest.py                 # 现有，保持不变
```

## 七、阶段五：质量校验与评估

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| OCR 字符准确率 | 每部分抽 3–5 页人工校对 | ≥ 98% |
| 表格完整性 | 对比抽样页表格行列数、数值 | 关键表（GI、DRIs）100% 正确 |
| 覆盖率 | 页数 → chunk 数、表格数统计 | 无整章丢失 |
| 检索效果 | 扩展 `docs/eval-baseline.md` 的评估集，加入本指南问答 | Recall@5 ≥ 80% |
| 幻觉抽检 | 抽查"指南中 GI 最高的是？"等数值型问题 | 答案可溯源到具体表 |

**数值型内容是本书的价值核心，也是最容易被 OCR 破坏的部分，必须单独建评估用例。**

## 九、风险与对策

| 风险 | 影响 | 对策 |

### 10.2 分档说明

**A 档｜有完整文本层，可直接解析（无需 OCR）**

- `014-2022+产褥期妇女膳食指导.pdf`、`婴幼儿辅食添加营养指南.pdf`
  —— 均为**官方标准文件**，版面规范，抽取文本为干净中文，无乱码，自带「前言 / 起草单位 / 术语定义 / 规范性引用文件」等标准结构。
  **是 RAG 质量最高的信源，建议优先入库。**
- `崔玉涛自然养育法.pdf`
  —— 正文 251/264 页有文本层，抽取质量优秀（完整段落，无乱码）。
  13 个无文本页中 11 页是**整页图片**（章节扉页 / 照片），2 页（p5、p177）是真空白。
  **处置：跳过纯图页即可，不需要 OCR。** 若需保留插图，可对这 11 页单独生成图注。

**B 档｜纯扫描，必须 OCR**

- `中国居民膳食指南（2022）.pdf`（彩色，含宽表，难度最高，作为试点）
- `崔玉涛育儿百科 Z-Library.pdf`（610 页，灰度扫描，工作量最大）
- `0-3岁宝宝喂养同步指导.PDF`（灰度 245 DPI，仅 1 个未嵌入、无 unicode 映射的 Helvetica，属装饰字体，无可用文本）

### 10.3 关键判断依据

- **`pdffonts` 字体数为 0** → 必然无文本层，直接判定为扫描件。
- **字体数 > 0 但不等于有文本**：`0-3岁宝宝喂养同步指导.PDF` 有 1 个 Helvetica（`emb=no`、`uni=no`），
  但逐页抽取文本为 0 字符 —— 说明该字体仅用于装饰，**必须以逐页文本覆盖率抽样为准，不能只看字体数**。
- **图文混排书会有少数无文本页**：`崔玉涛自然养育法` 的 13 个无文本页经 `pdfimages -list` 确认多为整页图片，
  属于正常现象，不影响整体判定为"有文本层"。

## 附：方案要点速记

1. **扫描书第一步必须 OCR**，不是 PDF 解析；但必须先普查，别对已有文本层的书做无用 OCR。
2. **表格是最大风险，也是最大价值**，必须结构化识别，宽表保留 HTML。
3. **标题层级 = 分块边界 = 检索质量**，必须还原"部分>章>节"。
4. **每个 chunk 注入面包屑上下文**，是提升中文 RAG 命中率性价比最高的一招。
5. **复用现有 bge-m3 + tsvector + RRF + KnowledgeChunk**，不引入新技术栈。
6. **先跑通 1 本 20 页试点，再批量**，避免 378 页跑完才发现表格全错。
7. **判定文本层要逐页抽样**，`pdffonts` 字体数 > 0 不等于有可用文本。
